# PandaVoice-dist — раздача обновлений Panda Voice

Публичный репозиторий, из которого приложение **Panda Voice** само узнаёт о
новых версиях и скачивает их. Исходный код живёт отдельно, в приватном
репозитории `Contento-R/PandaVoice`; сюда попадают только собранные архивы.

## Как это работает

1. При запуске приложение читает `latest.json` (raw-ссылка, без токена —
   репозиторий публичный).
2. Если версия в манифесте новее установленной, архив из `updates/`
   скачивается в фоне в папку «Загрузки», а контрольная сумма сверяется
   с `sha256` из манифеста.
3. Пользователю показывается вопрос «Установить сейчас?» — **молча ничего
   не ставится**. По согласию файлы заменяются, приложение перезапускается.
   Настройки, история диктовок и словари сохраняются.

Отключить автозагрузку: `auto_download_updates: false` в `config.json`
(тогда приложение только уведомляет). Полностью выключить проверку:
`update_check: false`.

## Формат `latest.json`

```json
{
  "version": "v1.8.7",
  "name": "PandaVoiceApp-v1.8.7-update.zip",
  "url": "https://raw.githubusercontent.com/Contento-R/PandaVoice-dist/main/updates/PandaVoiceApp-v1.8.7-update.zip",
  "sha256": "6941e6...",
  "notes": "Что нового — показывается пользователю в окне вопроса"
}
```

| Поле | Обязательное | Назначение |
|---|---|---|
| `version` | да | Версия вида `vX.Y.Z`; сравнивается с установленной |
| `name` | нет | Имя файла при сохранении (иначе берётся из URL) |
| `url` | да | Прямая ссылка на архив обновления |
| `sha256` | нет, но желательно | Проверка целостности до установки |
| `notes` | нет | Краткий список изменений для пользователя |

## Выпуск новой версии

Автоматически: workflow `Release` в репозитории с исходниками собирает архивы
и публикует их сюда (нужен секрет `DIST_TOKEN` — токен с правом записи в этот
репозиторий).

Вручную:

```bash
cp PandaVoiceApp-vX.Y.Z-update.zip updates/
sha256sum updates/PandaVoiceApp-vX.Y.Z-update.zip   # вписать в latest.json
git add -A && git commit -m "vX.Y.Z" && git push
```

Старые архивы можно удалять — приложение всегда берёт тот, что указан
в `latest.json`.
